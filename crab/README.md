# EEC CRAB jobs

The active OO and ppRef R=0.4 data/MC submission instructions are in
[RUN3_CAMPAIGN.md](RUN3_CAMPAIGN.md). Its `submitRun3.py` driver plans tasks
by default; `--submit` explicitly sends the reviewed jobs.

The versioned [OO](OOForestfiles/manifest.json) and
[ppRef](ppRefForestfiles/manifest.json) partition manifests document the
Vanderbilt signal lists and their 35 reserved pilot donors. The previous
mixed/perpendicular campaign instructions are preserved under
[archive/run3_previous_campaign.md](archive/run3_previous_campaign.md).
Run 2 cards, configurations and input lists are archived together in
[archive/run2/](archive/run2/).
