# Archived Run 2 CRAB inputs

These are the original 2017 pp and 2018 PbPb cards, CRAB configurations and
input lists. They are preserved byte-for-byte as historical material. Their
relative paths referred to the former `crab/` directory; restore them there
in a separate checkout before reproducing an old submission. New OO and ppRef
tasks use the R4 catalog and the active `crab/` entry points.
